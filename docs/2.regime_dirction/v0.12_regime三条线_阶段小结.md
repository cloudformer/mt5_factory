## 线 1:八象限 × PF —— 暂停

**做过什么**:每个策略的交易按 regime 八格分组,看每格的 PF(盈利因子)。

**为什么停**:

- PF 跨品种混单位(金的一点 ≠ 欧元的一点),汇总格的数字不可比,只能参考
- 更根本的:**PF 是个比值,格子里笔数一少就疯狂晃动**,几十笔的格子算出的 PF 说明不了任何事

**换成了什么**:改看"这笔是赢是输"(线 2)。计数比比值稳。

## 线 2:八象限 × 胜负 —— 暂停(这轮的主战场)

### 交易怎么分类:换过一次

**旧口径(废弃)**:按 R 倍数分四类 —— 大赢 >2R / 小赢 / 小亏 / 大亏 <−1R。

**为什么废**:固定止损止盈的策略上**必然塌成两类**。实测某策略:

```
大赢 27.7% · 小赢 1.9% · 小亏 0.0% · 大亏 70.4%
```

原因:`rr=2.4` 让所有止盈都超过 2R 全进"大赢";佣金 7 点让正常止损变成 −257 点超过 1R,全进"大亏"。四类白分。

**新口径(在用)**:按**出场原因**分四类 —— 止盈/锁利 · 正常止损 · 跳空有利 · 跳空不利。
出场方式不受 rr 和佣金影响,而且跳空两类直接回答"哪种天气容易被缺口打穿"。

> **跳空是什么**:价格不连续,一开盘就跨过了你的止损/止盈价,只能按开盘价成交。
> 不利 = 亏得比计划多(止损被打穿);有利 = 赚得比计划多。常见于周末跳空、重大新闻。

### 判据一路补了三道门(都是被假信号逼出来的)

| 门 | 干什么 | 为什么加 |
|---|---|---|
| 该格 ≥30 笔 | 格子本身不能太碎 | 原始判据 |
| **该类在该格 ≥10 笔** | 分子也不能太碎 | 报出过 `富集 3.77x(3/43笔)` —— 3 笔算出来的 |
| **该类合计占比 ≥10%** | 占比太小的类只提示不判定 | 跳空类只占 3%,却贡献了统计量的七成 |

第三道门的实证:某报告统计量 61.86,踢掉两个跳空类后剩 **18.56** —— 七成的"显著性"是占 3.5% 交易量的类撑起来的,把"盈亏在分层"和"跳空集中"两件事混成一个数,谁都读不出。

挂了「！样本不足」的类**数字照给、颜色照标**,只是不参与判定(和 oos_v2、矩阵页同一套规矩)。

### 试过的方向和结果

**周期**:M15 → H1 → H4 都试了。

| 周期 | 单策略笔数 | 结果 |
|---|---|---|
| M15(slow285) | ~400 | 无信号 |
| H1(slow50) | ~3500 | 信号最多 —— **但那是笔数多带来的假象** |
| H4(slow200) | ~260 | 零信号 —— **笔数太少,根本测不出** |

> **关键教训**:笔数差 14 倍,能测出的最小效应就差 3~4 倍。"H1 信号多、H4 没信号"**不是**真实差异,是统计功效差异。
> 八个格 × 几百笔 = 每格几十笔,单策略层面**结构上就读不出东西**。

**曾以为找到的规律(已否定)**:「长短趋势背离时开仓更容易止盈」。

手算四份报告,三份同方向(+4.9 / +2.5 / +4.2 个百分点),看着很像真的。**池化 12.5 万笔后塌了**:

```
grain-H1(81个)   +1.9 / +2.8 / +1.6 / +2.8   (四个 regime 版本)
grain-H4-50      +0.1 / +1.7 / +0.7 / +1.7
grain-H4-31      −3.1 / −0.1 / −1.6 / −0.1   ← 转负
```

手算的那个 +4.9 是全批里最强的一个策略 —— 典型的"挑出最漂亮的样本"。

**同时对照组暴雷**:三个单维本该都接近 0,实测 `长趋势 +0.1 · 短趋势 +0.3 · 波动 −1.7~−2.5`。波动维自己的效应和"背离"同量级,说明那不是纯交互效应。

### 捞到的两条真东西(线 2 唯一的产出)

**① 波动维**:高波动日开的仓,止盈率比低波动日低 **1.7~2.5 个百分点**。
四个 regime 版本、三个批次**全是负的、量级稳定**。机制干净:波动大 → 价格晃得凶 → 止损更容易被扫、止盈更难走完。
它本来是当对照组放进去的,自己冒出来的 —— **不是从几千个格里挑出来的**,这点很重要。

**② 执行风险**:高波格里"止损被跳空打穿"的比例是平均的 **2.2 倍**(4.2 个标准差,过了严格的多重比较校正)。
这不是盈利信号,是**防守用**:高波日放宽止损或降手数。

## 线 3:批次维度(刚做完,是基础设施)

**解决什么**:以前跑分析要拼"模板 + 品种 + 周期"三个下拉,还会混进无关策略。现在**一次实验 = 一个批次**,选一下就圈准。

- 生成策略时填的标签存进 `strategies.basis`,自动带时间戳保证唯一
- 回测页、规律页都有「批次」下拉,显示 `已测 N/总 N`
- 一次跑批产出一份报告,报告里存着当时的判据快照
- 历史报告列表里三行摞一起 = 跨批对比,不另开页面

**已有的数据资产**:

```
grain-H1260812-222916   H1   81 个   已测 81
grain-H4260812-222706   H4   50 个   已测 50
grain-H4260812-222832   H4   31 个   已测 31
优化策略260812-222749    M15  5000 个  已测 10
实验组A-趋势跟踪海龟-金H1  H1   50 个   已测 50
```

> 注:H4 那 81 个被拆成 50+31 两批(生成上限截断后补跑,时间戳不同 = 两个批次),**不能合并选**。

**还有个没修的**:批次下拉里 50 项中有 45 项是"AI 克隆"的单策略(`basis` 这列身兼两职:生成批次标签 + AI 克隆的生因)。已加 `only_tested` 过滤但没打中 —— 正确判据是 **策略数 ≥2**(单个策略不叫批次,点名用「按ID」)。

## 方法论:这轮验证出来的几条规矩

1. **单策略不下结论,必须池化。** 八格 × 几百笔结构上就读不出;跨策略堆几万笔才有意义。
2. **效应量 > p 值。** 同品种同模板的策略仓位高度重叠,几十万笔远不是几十万个独立观察,任何 z/p 都虚高。只看"差几个百分点"和"跨批次跨品种一不一致"。
3. **对照组是照妖镜。** 主判据之外必须同时算几个本该为 0 的对照;对照亮了,主判据就不可信。这次就是靠它发现"背离效应"不纯。
4. **判据事先定死。** 从几千个格里挑最漂亮的必然挑得到 —— 81 策略 × 4 版本 × 8 格 ≈ 2600 次比较,3.7 个标准差的格子**本来就该出现约半个**。
5. **各 regime 版本独立评估,绝不跨版本挑最好。** v1 的 BBA 和 v4 的 BBA 定义不同(高波分位切点不一样),同名不同义,跨版本挑 = 数据挖掘。
6. **换品种重现比任何 p 值都硬。** 库里 GBPUSD/XAUUSD 有现成回测行,这是最便宜的硬检验。

## 试过但确认不走的路

- **缩短 regime 口径**:实测格龄中位已经只有 3 天(组合格)、年翻转 45 次,结构指标全达标。再缩就跌破持续性标准。**而且为了让信号好看去换口径 = 循环论证,明令禁止。**
- **把 regime 做成日内(H4/H6 一个格)**:合成数据实测,细化粒度会按 bar 尺寸**成比例砍掉格龄**(D1 的 2 天 → H4 的 0.33 天),持续性直接不过。就算把所有周期同步换算,也只能回到 0.58 天,因为采样密了会看见 D1 压根没观察到的短暂穿越。细化的真实收益是**精度**(标签更新鲜、贴格更准),不是**速度**。
- **再批量生成策略**:三百多个够用了,缺的是读数不是原料。
