# v0.8 regime_abstract 口径试验田设计

2026-08-08 与 Frank 定稿。定位：**口径实验台** —— 把 regime 从"写死的三维(长/短/波)"
抽象成"指标库 × 自由组合"，在冻结成正式版本之前，用中性记分卡验证一套口径稳不稳。
终极服务于秘方：`feature 定义版本 + 状态键 + 策略参数 + 20年统计 + 预测验证战绩`。

## 两层结构

**代码层 = 指标函数库**（词汇表，代码注册，每个函数 = 名字 + 参数 schema + 二桶规则）：

| 函数 | 语义 | 桶 |
|---|---|---|
| `ma_side(period)` | 收盘在 N 日均线上/下 | A/B |
| `ma_slope(period, days)` | 均线 N 天斜率正/负 | A/B |
| `atr_regime(period)` | ATR vs 滚动年中位 高/低 | A/B |
| `range_pos(days)` | 收盘在 N 日高低区间上/下半 | A/B |
| `ma_cross(fast, slow)` | 快线在慢线上/下 | A/B |
| `ret_sign(days)` | 近 N 日累计涨/跌 | A/B |

要新指标 = 库里加函数（进 git、过测试）。第一版全二桶（状态串纯 A/B，八格/十六格组件复用）；
三桶后置。

**配置层 = 口径定义**（试验田页面自由拼，纯数据）：
```json
{"features": [
  {"fn": "ma_side",    "params": {"period": 200}},
  {"fn": "ma_side",    "params": {"period": 20}},
  {"fn": "atr_regime", "params": {"period": 14}}
]}
```
状态键 = 各 feature 桶字母拼串（3 维 = AAA…BBB 八格，4 维 = 十六格）。
现有 v1/v2 = 上例的特例，**平滑兼容不推翻**。

## 维数护栏（2026-08-08 Frank 定）

**3~4 维最佳（8~16 格）**。页面默认上限 4 维（可配），超出只警告不硬拦 ——
20年≈5200交易日：5维32格≈160天/格（分布不均即没样本），8维256格≈20天/格=纯噪声。
真正执法的是记分卡（覆盖均衡/持续性会把爆炸口径判死）。

## 记分卡（口径评定四标准 — 全中性指标）

| 标准 | 指标 | 默认门槛(可配) | 防什么 |
|---|---|---|---|
| 持续性 | 组合格龄中位(天) / 年翻转次数 | ≥3 天 / ≤60 次 | 一天一变的神经质口径(格龄必须显著长于持仓) |
| 覆盖均衡 | 最稀格占比 / 最密格占比 / 空格数 | ≥5% / ≤35% / 0 | 稀到无统计价值的格 |
| 区分度 | 波动态间日均真实波幅比 / 趋势态次日收益均值差 t 值 | ≥1.5× / \|t\|≥2 | 各格实际是同一种天气(标签名不副实) |
| 维度不冗余 | 任两维同向一致率 | ≤75%(≥90% 砍一维) | 两维是一回事 |

**铁纪律：试验田永远不显示"哪个口径让策略更赚钱"** —— 用策略盈利选口径 = 循环论证。
策略×口径的赚钱关系由预测验证(v0.7 批次3)在时间轴上用未来数据裁决。
门槛数值是常规经验起点，首轮全过/全不过允许校一次，选定后连同门槛冻结。

## 页面（自动化筛选页同款骨架）

```
口径实验: 维1..4(下拉选函数 + 参数框, ＋加一维/✕删一维) · 品种范围 · 年数 → [跑实验]
记分卡:   每品种一行 × 四标准读数(达标绿/不达标红) + 总评
历史实验: 每次一行报告(配置 + 记分卡结果) · 预览/json 下载(喂 AI 提下一轮参数)
[冻结为新口径版本]: 全部达标才亮, admin — 配置原样写进 regime_versions(features 新格式)
```

## 数据与兼容

- 实验现算不碰正式时间线（D1 级，20年/品种 ≈ 5200 行，秒级出结果）；
- **实验留报告**（照筛选页模式）：新表 `regime_abstract_screens`
  （id/created_at/config/scorecard/owner_id），AI 迭代闭环靠它；
- 冻结 = 实验配置写进 `regime_versions.params`（features 数组新格式）；
  timeline 计算认新旧两种格式（老 {long_ma,short_ma,atr_n} = 三 feature 翻译），存量零迁移；
- 冻结后被门/矩阵/筛选/预测引用的机制全不变。

## AI 配参数闭环

AI 读历史实验报告 json → 按记分卡结果提下一批 features 组合 → 页面批量测试 → 人拍板冻结。
（走 AI 调参同款模式：AI 只出配置，配置进库，代码永远进 git。）
