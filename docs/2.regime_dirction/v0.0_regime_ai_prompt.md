# v0.0 单策略AI调参·1-Regime 提示词约束口径

2026-08-10 与 Frank 定稿。**唯一实现在 `containers/api/src/routes/strategies.py`
的 `_REGIME_AI_PROMPT_HEAD`（git 可审）；本文件记录"为什么这么约束"，改口径先改这里对齐。**

## 定位

人桥版两问分析：把一个策略当探针，用它的全量回测去评价"哪副 regime 眼镜能把交易分出层次"，
并产出该策略可直接使用的 gate。**AI 只有建议权**——产出是待检假设，
最终由回测（尺子）裁决、由预测验证（创建时间锚）记账。

边界要清醒（2026-08-10 Frank 定的原话）：这是**在确定的策略面前、在有限的 regime 下找规律**。
三个"有限"都在：探针固定 / 版本只有货架上这几副 / 数据一千多笔二十年。
四份独立报告一致显示 `dispersion 是 separation 的 3~5 倍`，
2026-08-11 置换检验进一步查明：**格间分离度与随机打乱格标签无异**（不是"有信息但被噪音盖住"，
是"这项指标不携带信息"）。所以本方法的产出强弱天然分三档：

| 强度 | 产出 | 可信度 |
|---|---|---|
| 最硬 | **坏格识别**（跨版本、跨时代都亏的格） | 高——排除它们是最可复现的收益来源 |
| 中等 | 好格识别（相对分两段同向） | 能用，优势薄 |
| 最弱 | **版本排名** | 切点差半年就翻转，噪音级 |

与回测哲学同构：回测最可信的是"亏的必亏"，regime 最可信的是"这种天气别做"。

## 数据形态（精简模式，2026-08-10 起）

**贴格与聚合全在数据库侧完成，AI 零计算只读表**——起因是网页版 AI 面对逐笔原料
要么编造自洽假账（把总账按比例摊到格里，加总全对但格账是编的），要么诚实认输
（"需要预聚合数据"是 AI 自己的原话）。改法：

- 每版本给 `year_cells`（年×格）+ `month_cells`（月×格），行 = `[切片, 格, 笔数, 赢, 毛利, 毛损]`；
- 提示词两段：①全部版本预聚合数据 ②任务指令（压轴带开始口令）；
- 多附件会被平台静默丢段（实证），故提供「合并一份」单文件下载。

## 三层验收（每层堵一种偷懒）

### 1. computed_by —— 给台阶，堵编造
明写"没代码工具就填 `none` 认输，这是合法答案"。有体面退路，AI 就不必为交差硬编。
（1-Regime 精简模式下查表即可，`none` 也算合格；2-时间页要求必须 `code`。）

### 2. probes 探针 —— 堵"没读数据"
服务端点名 5 个 `v版本|年|格` 行，要求原样照抄 `[笔数, 毛利, 毛损]`。
**真实答案不进提示词**，只返回给页面自动核对；答错 = 整份作废。
这是地基：必须真打开数据才能过，蒙不了。

### 3. 三道必做检验 —— 堵"读了但凭感觉"
数字填进 `versions[].metrics`，不做即结论不合格：

1. **周期基准剥离**（最容易犯的错，实证：某策略早段 PF 0.98 → 近5年 1.31）
   先算整个策略不分格的分段基准；有漂移时"近5年各格普遍变好"是时代红利。
   每个格必须同时给 **绝对 PF** 与 **相对分 = 格PF ÷ 同期全局基准PF**，两者同向才算有效。
2. **格间分离 vs 格内离散（仅诊断，2026-08-11 降级）**
   `separation`（各格全量 PF 的 log 加权标准差）/ `dispersion`（每格逐年 PF 同法后加权汇总）
   / `ratio`。**置换检验实证：ratio 的随机水平本身就有 0.20~0.23，常见观测值全落在零分布内
   （p=0.16~0.51）→ ratio 高不构成任何版本的加分理由**（高值多半是笔数分布造成的假象）。
   只作诊断报出；离散是分离的数倍 → confidence 封顶 medium。
3. **半样本一致性**（2026-08-10 收口，此前是唯一裸奔的判据）
   - **切点钉死**：按**累计笔数中位数**对半，**禁止按年份中点**——交易分布不均
     （早年稀近年密），按年切两半笔数悬殊。这正是两个模型 ranking 打架的根因
     （同一数据切点差半年，rho 从 0.60 掉到 0.29，名次翻转）。
   - **稳健性复检必做**：再按 4 个等长块算 6 对块间排序相关均值 `rho_blocks`。
     与 `half_rho` 矛盾（一正一负/≈0）= 单一切点的巧合 → **该版本不得靠 half_rho 排前，以块为准**。

### 4. 显著性 = 置换零分布（2026-08-11 定，强中弱的唯一依据）

**为什么不能拍绝对常数**：ratio / rho 的"随机水平"不是 0，取决于笔数分布与切片结构。
同一个 0.30 的 ratio，在这个策略上是随机水平，在另一个策略上可能显著。

**零假设怎么构造（关键）**：在**每个时间切片内部随机打乱格标签** ——
保持该切片的笔数/毛利/毛损完全不变，只切断"格 ↔ 业绩"的对应，重复 ≥1000 次。
零分布因此保留了笔数分布、切片结构、周期漂移等一切其他结构，
p 值衡量的正是"这个口径比随机分类强多少"。

**分档规则（p 值，不是绝对值）**：

| 档 | 条件 |
|---|---|
| 强 | 三项中 ≥2 项 p<0.05，且至少一项是可复现性检验（half_rho / rho_blocks） |
| 中 | 恰好 1 项 p<0.05，或 ≥2 项 p<0.10 |
| 弱 | 无一项 p<0.05 |

**多重比较**：N版×3项 Bonferroni（α=0.05/(3N)），校正后仍通过的才可称"硬"，
否则措辞用"边缘/仅提示"。

**跑不了置换的兜底**：经验阈值 `ratio≥0.35 / half_rho≥0.45 / rho_blocks≥0.22`
（约为常见数据规模下零分布 p95 的上包络），须标 `null_method="fixed_threshold"`
并注明"显著性未经标准化"。

**措辞纪律**：观测值落在零分布内 → 写"**与随机标签无异**"（该指标不携带信息），
不要写"弱于噪音"（暗示有信息但被盖住）—— 两者结论不同。

**首次实证（2026-08-11，某 M15 策略 1590 笔 × 4 版本 × 2000 次置换）**：

```
      ratio(obs/null均值/p)   half_rho(obs/p)   rho_blocks(obs/z/p)      档
v1    0.222 / 0.217 / .43    0.000 / .29      -0.095 / -0.17 / .53      弱
v2    0.226 / 0.234 / .51   -0.071 / .41       0.468 / +3.61 / .0015    中(唯一过 Bonferroni)
v3    0.250 / 0.203 / .19    0.000 / .26       0.020 / +0.52 / .27      弱
v4    0.298 / 0.234 / .16   -0.071 / .33       0.187 / +1.57 / .0845    弱(边缘)
```

读法：**四版 ratio 全落在随机水平** → separation 在本数据上不携带信息（v4 的 ratio 最高纯属
笔数分布假象）；只有 v2 的 rho_blocks 显著且过 Bonferroni → v2 第一比"弱信号"硬一些。
门的结论不依赖 separation：坏格靠"跨版本一致 + 两段同向 + 样本厚"选出，
版本靠 rho_blocks 选出，confidence 仍锁 medium。

### 5. 版本排序不稳时的兜底
各版本 ratio/rho 挤在一起时，**如实写明"版本排序不稳定"**，改按
【坏格识别的一致性】定第一名——哪个版本把公认坏格分得最清楚（相对分最低、两段同向、样本厚）选哪个。

## 路径质量：第二维（2026-08-11 Frank 定，与 PF 高低同权）

**问题**：只看全量 PF 会把"靠爆发拉高均值"的格当宝。经典场景——
格A `PF 1.9 逐年稳`  vs  格B `PF 2.2 但半数年份亏`，后者数字漂亮但期望是幸存的爆发。

**每个候选格必须报路径三数**（≥5笔的年切片才计，薄年份另列）：
`有交易年份数 / 其中 PF<1 的年份数 / 最低年份 PF`。

| 路径档 | 判据 | 倍率建议 |
|---|---|---|
| 稳 | 亏损年 ≤1/4 且最低年 ≥0.8（几乎不穿 1） | 可 1.0，不因方差降档 |
| 不平 | 亏损年 ≤1/3 且最低年 ≥0.6（跳但基本不穿 1） | 0.6~0.8，evidence 明写"路径不平，逐年 X/Y 年亏，最低 Z" |
| 爆发型 | 亏损年 >1/3，或最低年 <0.5，或去掉最好的 1~2 年后全量 PF 跌破 1 | **不入选** |

**为什么爆发型是"不选"而不是"降倍率"**：降倍率只缩小亏损，不改变期望的虚假；
实盘错过那一两段爆发就是纯亏。这与策略预测页看批次色带的心法同源——
**看短板和亏批数，不看均值**。

**排序纪律**：`PF 1.9 逐年稳` **优于** `PF 2.2 半数年份亏` —— 前者回撤浅、
可上更大仓位、资金曲线更好。推荐必须按此排序，不许按全量 PF 大小排。

**倍率是建议值，人拍板**（2026-08-11 Frank 定）：AI 的职责是把"为什么给这个值"的数字
摊开（相对分两段/笔数两段/路径三数/跨版本一致性），让人能否决并改成别的值；
未入选格同样要写清"哪个数字不合格"，不能只说"排除"。

## 选格与倍率规则

- 权重：近 5 年 ≈66% / 更早 ≈34%，**作用在相对分上**（有漂移时按绝对分加权会选出一堆时代红利格）；
- **倍率按证据强度给，不按 PF 高低给**：最硬 = 1.0，中等 = 0.6~0.8，
  **弱证据 = 不入选**（禁止用低倍率把样本薄/单段爆发的格硬塞进来）；
- 证据强度分级：
  - 最硬 = 跨版本一致 + 两段绝对与相对同向 + 笔数充足
  - 中等 = 单版本内两段同向但样本偏薄，或绝对过关而相对勉强
  - 弱 = 年度切片多数 <5 笔 / 只有少数年份有记录 / 全量靠单段爆发拉高
  - **稳定亏的格往往比稳定赚的格证据更硬**——优先确认它
- 信心硬性下限：regularity 为"弱"（无一项 p<0.05）/ 可复现性两项 p 均 ≥0.05 /
  `dispersion` 数倍于 `separation` / 入选格含弱证据 → 任一条成立即封顶 medium。

## 落地闭环

```
1-Regime 生成提示词 → 喂 AI → 粘回复 → 页面自动验收(探针+报告齐全)
  → 全绿预填门面板(勾格/倍率可改) → 人拍板克隆(basis 自动记 AI模型·信心·ranking)
  → 全量窗回测, 与无门父/其他门变体同桌对比 → 上模拟 → 策略预测页按创建日锚点记账
```

## 实证记录（改口径的依据，勿删）

- **AI 会编自洽假账**：曾出现 8 格加总与总账分毫不差、但格账全是按比例摊派的回复
  （胜率全部≈母体、PF 全挤在 0.95~1.26）→ 催生探针 + 精简模式；
- **"近5年权重"会误判**：有全局漂移的策略上，按绝对分加权会把时代红利记到格头上
  → 催生周期基准剥离（第一份漏查的模型选了错版本）；
- **half_rho 对切点敏感**：某版本 0.738 换四块复检后变 −0.083 → 催生切点钉死 + rho_blocks；
- **规则改变行为的证据**：加"弱证据不入选"后，同一模型从"4 个格含 2 个薄样本低倍率"
  收敛到"2 个格、弱的直接不要"；
- **方法论收敛的证据**：两个不同模型（Gemini 2.5-pro / Opus 5）在同一策略上
  ranking、separation 数值、入选格、坏格判定、confidence 全线一致；
- **绝对阈值不可靠**：置换零分布显示 ratio 的随机水平就有 0.20~0.23 → 强中弱改用 p 值判定，
  separation/ratio 从"判据"降级为"诊断"（2026-08-11）；
- **门不是带了就好，是选对才好**：同族七行同窗实证 —— 好门把 PF 1.077 拉到 1.37 且净点更高，
  而含周期红利格/坏格的门反低于无门父（1.126 vs 1.15）。少选格更纯（单格 1.478 >
  两格 1.381 > 三格 1.34），低质量格应删不应打折，正贡献格不该打折（×1 比 ×0.8 多赚 5071 点）。
