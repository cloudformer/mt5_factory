# v0.3 策略 metadata 设计(regime 门→手数)(2026-07-31 与 Frank 定版 · 未开工)

> 模板参数(params)管"信号怎么算",metadata 管"执行怎么裁"。
> 数据观(Frank 定,本设计的总纲):**垃圾都被覆盖,留下的都是资产**——
> regime 时间线(调试生成,可重建)、策略(调试生成)、M1(宝贵资产)、
> 回测数据(最新鲜、随时更新、无垃圾)。一切设计精简、免维护、不生成垃圾。

## 一、metadata 列

```sql
ALTER TABLE strategies ADD COLUMN metadata JSONB NOT NULL DEFAULT '{}';
```

```json
{
  "regime": {
    "version": null,              // null=跟随全局默认版本(v0.2), 或钉死版本号
    "cells": {"AAA": 0.5, "ABA": 0.1}   // 格→手数倍率; 未列出的格=不开新仓
  },
  "trail": { }                    // 将来从 params 迁入(存量不追改, 新写走 metadata)
}
```

- **显式格,不存邻格/掩码语法**:`?BA`/邻格是录入时的糖(页面/AI 展开成显式 cells 再存),
  库里口径唯一,回测/runner 不解析第二套语法
- **倍率不是绝对手数**:实际手数 = 挂载点手数 × 格倍率(同策略挂不同账户不用改门)
- **未列格 = 不开新仓**;已有持仓照常由服务端 SL/TP 管(门是入场门,不是强平门)
- **可改、不留痕**:最优情况是定了就不改;留痕没人看只增垃圾。
  成绩与配置的对应关系由回测行自带 regime 配置解决(见下),连快照都不需要

## 二、回测行加 regime 维度(覆盖问题的终解)

```
backtests 主键: (strategy_id, symbol, regime配置)
  regime = 空       → 全量行(引擎无门, 探索原料)
  regime = 配置串   → 带门行(引擎真跑该门的成绩)
```

1. **双跑同窗**:配了 regime metadata 的实例,一次回测任务引擎跑两遍(同一窗口)——
   无门→UPSERT 全量行,带门→UPSERT 带门行。原料永远新鲜,全量 vs 带门同窗同参,
   唯一变量是门(对比三铁律自动满足)。无 metadata 的实例照旧单跑,零变化
2. **一实例一品种最多两行,免清理**:写带门行时顺手删掉该 (strategy_id, symbol) 下
   其他带门行(旧门配置尸体)——库里永远只有"全量 + 当前门",不留定时清理的活
3. **正式成绩取法**:带门行有就是它,没有就是全量行(排名/矩阵/对账同一规则)

## 三、两级验证(先便宜后精确)

| 级 | 机制 | 成本 | 精度 | 用途 |
|---|---|---|---|---|
| 读时模拟 | 对全量行 trades 按任意 version×cells×倍率 现拼 | 跑一次试百种 | 定性可信;看不见"门跳过一单后仓位空出来接的下一单" | 筛:找方向/比格/调倍率 |
| 引擎真跑 | 入场时查当日格(该版本 timeline), 不在 cells 跳过, 在则按倍率 | 每配置一跑 | 占位级联真实 | 定案:正式成绩/对账/实盘 |

闭环:`无门回测(全量行) → 矩阵页模拟N种门 → 选定写 metadata → 双跑同窗
→ 两行并排看门的真实增益 → demo/live: runner 同门语义 → 对账验证`

## 四、纪律(Frank 定)

- **线上线下必须一致,不能脱节**:runner 与引擎同一份 metadata、同一个门语义(入场查当日格)
  ——系统保证;"上线后不改 metadata"是流程纪律,不做锁(节奏是 20 年测定、几周下线,
  不存在线上长期改配置的场景)
- demo 与 live 同待遇,无升降级概念
- runner 侧实现暂不开工(先回测侧调试 regime 与象限)

## 五、铁律对照 / 不做什么

- 最小化:一列 + 回测主键加一维;判重/并存/免清理全靠约束和写时收尾,零定时任务
- 可关联:metadata 挂实例,回测行挂 (实例,品种,门),门→版本→参数一路 JOIN
- 无状态:门的真相在库;runner 15s 刷新自然带上(线上生效方式暂不细化)
- 不做:metadata 变更历史/审计、门的强平语义、每格方向裁剪(dir long/short —
  目前无需求,cells 锁死纯倍率数字,将来有需求再扩结构)、上线锁
