# v0.5 Regime 筛选(批量粗筛 + 落库报告)(2026-08-03 与 Frank 定稿 · 已实现)

> 测试性质的可插拔功能: 三个自有文件 + 四个单行挂钩, 移除手册见文末。
> 定位: 漏斗关1.5 — 批量生成的策略在 5 年回测后, 自动检验"regime 格子的时间稳健性",
> 通过的打标签进人工 20 年深看, 不过的删除归档(可逆)。

## 一、判据(定稿)

```
数据源: 该策略回测行(窗口不足【总计年】→ 跳过不判); 判定窗统一裁到【近总计年】—
        回测行更长(如 11.5 年老行)时更早的逐笔不参与, 判据口径一致(2026-08-04 定);
        货币选项见运行选项
报告三层读数(2026-08-04 定): 整窗净点/PF → 每格净点/PF → 每切分前后段净点/PF → 结论
        (明细行 ▾ 展开"格×切片"子表; PF ∞=无亏损)
切分:   每个切分点 b = 近 b 年(后段) vs 剩余(前段), b 可小数(0.5 / 3.8 / 4.5)
合格格: 某格在【每种切分的前后两段】都满足
          净点 > 净点阈值(默认 0) 且 PF > PF阈值(默认 1 — 两默认等价, 调高即收紧,
          无亏损段 PF=∞ 恒过; 手续费已扣在逐笔里)
          且 该段该格笔数 ≥ 地板(默认 5, 改 1≈关闭)
通过:   全切分达标的格子数 ≥ 至少合格格数(默认 1)
参数(2026-08-04 扩展, 全可配, config 键 regime_screen, 页面可改):
  {"window_years":5, "boundaries_years":[1,2,3,4], "min_cell_trades":5,
   "min_pass_cells":1, "min_net_points":0, "min_pf":1.0}
报告参数快照全记(含 regime 版本), 事后可校参
```

- 粗筛地板(5 笔)≠ 结论纪律(20 笔): 地板防掷硬币, 20 笔留给幸存者的人工阶段
- 用盈亏选策略 = 漏斗天职, 合规; regime 口径全程冻结(循环论证禁令完好)

## 二、运行机制(2026-08-05 队列化定版, 六步走完 + 逐字段比对零差异)

```
① 生成一批(自动带时间戳标签)                                    ← 已有
② 全池清理: 筛选页点「开始筛选」→ 投 jobs 队列(kind=regime_screen)秒回
     worker 并行现跑回测(同一 jobs._run_one: load_m1+悲观撮合+UPSERT 回流 backtests)
     → 队列跑完 → api 心跳主节点收尾(services/screen.finalize, advisory lock 内):
       切片判定 → 落报告 → 打标签/归档 → 删空队列(幂等自清理)
     500 个 ~20 分钟(api 单线程) → ~3 分钟(9 worker); 关页面/重启 api 都不丢
   点名诊断(按 ID): 仍 api 内同步现跑现判, 只读不入库(几个 ID 秒级, 走队列绕远)
   判定逻辑全系统一份 = services/screen.py, 两条路共用(结果必然一致)
③ 报告落库(regime_screens 一跑一行, 点名诊断除外): 参数快照+汇总+逐策略明细
     页面服务端分页(500行全量进浏览器会卡死) + 通过优先排序 + 深层数字按需加载

数据安全铁则(改判定/收尾前必读, 代码注释同步):
  1. 任一任务 FAILED / 缺回测行 / 窗口不足 → 该策略记"跳过(未判定)", 永不归档
  2. 归档写入时重新校验 status='CANDIDATE'(防跑批期间被挂上机器)
  3. 预览模式除报告外零写入; 执行动作只在 finalize 内一次性发生
  4. 两个工种队列独立(backtest / regime_screen), 互不抹除; 同时跑只是排队
  5. 验收方式 = scripts/verify_screen_report.py: 报告明细 vs 同一份回测行现场重算,
     逐字段零差异才算数(2026-08-05 实测 10 策略 × 11 字段零差异)
```

## 三、basis 标签样例(打标前 → 打标后)

| 带批次标签生成 | `验尺A-经典Donchian20` | `验尺A-经典Donchian20｜regime筛过#3` |
| AI 调参子代 | `13笔SL合计-66016.2点, MAE p90为6657.4点, 略收紧止损… 〔局部搜索+证据驱动 · GPT-5.5〕` | 原文后追加 `｜regime筛过#3` |
| 克隆带门 | `克隆带门 parent=#3677-gate-v1-ABA1-BBA1` | 原文后追加 `｜regime筛过#3` |
| 空(老策略) | (空, 列表显示 —) | `regime筛过#3` |

- 列表页「标签」列直接可见; 搜索选"标签/生因"输 `regime筛过` 一键捞出全部幸存者

## 四、报告(regime_screens 表, 一跑一行)

```

明细(JSONB): 每策略 —
  ID · 摘要 · 窗口 · 总笔数 · 通过格(如 ABA·BBA) · 各切分合格格数(4/1·3/2·2/3·1/4) · 结论
页面: 导航「策略▾」→「Regime 筛选」= 参数区(可改存config) + 运行区(默认预览) + 历史报告区
```
