# v0.5 Regime 筛选(批量粗筛 + 落库报告)(2026-08-03 与 Frank 定稿 · 已实现)

> 测试性质的可插拔功能: 三个自有文件 + 四个单行挂钩, 移除手册见文末。
> 定位: 漏斗关1.5 — 批量生成的策略在 5 年回测后, 自动检验"regime 格子的时间稳健性",
> 通过的打标签进人工 20 年深看, 不过的删除归档(可逆)。

## 一、判据(定稿)

```
数据源: 该策略【主货币】的 5 年回测行(窗口不足 5 年 → 跳过不判)
切分:   按年切四刀 — 前4/后1 · 前3/后2 · 前2/后3 · 前1/后4
合格格: 某格在【每种切分的前后两段】都满足
          净点 > 0(≡ PF>1, 同一条件 — 手续费已扣在逐笔里)
          且 该段该格笔数 ≥ 地板(默认 5, 改 1≈关闭)
通过:   存在至少一个合格格
参数:   config 键 regime_screen = {"boundaries_years":[1,2,3,4], "min_cell_trades":5}
```

- 粗筛地板(5 笔)≠ 结论纪律(20 笔): 地板防掷硬币, 20 笔留给幸存者的人工阶段
- 用盈亏选策略 = 漏斗天职, 合规; regime 口径全程冻结(循环论证禁令完好)

## 二、运行机制

```
① 生成一批(带批次标签)                    ← 已有
② 批量回测 5 年(jobs 队列, worker 副本并行) ← 已有, 重活在这
③ 筛选页点「开始筛选」: api 请求内直接算    ← 轻活(读 trades+贴格, 100个=秒级), 不派 worker
     范围 = 批次标签 或 ID 列表, 先排掉: 已归档 / basis 含"regime筛过"(幂等, 不重复处理)
     模式 = 预览(纯报告零动作) / 执行(通过打标签, 未过归档)
     运行选项(2026-08-03 Frank 补) —
       regime 版本: v1/v2...(判定用哪套时间线, 不传=当前默认; 报告记录版本号)
       货币范围 = 判定数据源(品种主档无角色, schema/010 已简化, 不是范围过滤):
         main=只用策略主品种的回测行判(默认)
         all =该策略所有已回测品种每个独立判(各贴各的时间线), 全过才过;
              跨品种窗口不足的行不纳入要求(只加码不放水), 需先跑过跨品种回测
     范围铁则(2026-08-03 Frank 定): 只筛空闲(CANDIDATE)策略 — 在跑(demo/live)不进筛选,
       不做特殊分支, 要处理它们 = Frank 手动; 归属过滤同全站 scope
④ 报告落库(regime_screens 表, 一跑一行): 参数快照+汇总+逐策略明细, 供回看/校参
```

执行动作只有两个写入, 都是系统本来就支持的操作(等于自动化的人在点按钮):
- 通过 → basis 追加 `｜regime筛过#<报告id>`(一次 UPDATE, 停用功能=不再写, 已写=履历)
- 未过 → 归档, 死因 `regime_unstable`(可逆; 死因码进 AI 负样本)

## 三、basis 标签样例(打标前 → 打标后)

| 策略类型 | 打标前 basis | 打标后 |
|---|---|---|
| 批量随机生成 | `random` | `random｜regime筛过#3` |
| 带批次标签生成 | `验尺A-经典Donchian20` | `验尺A-经典Donchian20｜regime筛过#3` |
| AI 调参子代 | `13笔SL合计-66016.2点, MAE p90为6657.4点, 略收紧止损… 〔局部搜索+证据驱动 · GPT-5.5〕` | 原文后追加 `｜regime筛过#3` |
| 克隆带门 | `克隆带门 parent=#3677-gate-v1-ABA1-BBA1` | 原文后追加 `｜regime筛过#3` |
| 空(老策略) | (空, 列表显示 —) | `regime筛过#3` |

- 列表页「标签」列直接可见; 搜索选"标签/生因"输 `regime筛过` 一键捞出全部幸存者
- `#3` = 报告 id, 可溯源到那次筛选的参数与全量明细

## 四、报告(regime_screens 表, 一跑一行)

```
头部: 时间 · 模式 · 范围 · 参数快照 · 汇总(共N/通过X/未过Y/跳过Z含已通过多少)
明细(JSONB): 每策略 —
  ID · 摘要 · 窗口 · 总笔数 · 通过格(如 ABA·BBA) · 各切分合格格数(4/1·3/2·2/3·1/4) · 结论
页面: 导航「策略▾」→「Regime 筛选」= 参数区(可改存config) + 运行区(默认预览) + 历史报告区
```
