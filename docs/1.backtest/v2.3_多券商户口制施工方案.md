# v2.3 多券商·实例户口制 施工方案(2026-08-18 与 Frank 收敛,待"动工"指令)

## 定案口径(讨论已收敛,施工不再改)

1. **两字段**:broker 独立成列,不用 `XAUUSD@OD` 合格名(跨券商测试要拆字符串,否决);
2. **historical_bars 主键 → (symbol, timeframe, time, broker)**:broker 缀**末位**,
   现有查询执行计划逐字节不变 = 读路径可从容分批补参数;
3. **broker 值 = 全名字符串**(与 symbols.broker 同串,如 "MetaQuotes-Demo"/"OANDA"),
   不发明短码第二叫法(命名铁律);
4. **实例户口制**:strategies.broker = 实例落户券商(生成时取 config 默认券商)。
   排名主成绩 = 户口行;对账基准 = 户口券商数据;挂载校验 实例户口 == worker 券商;
5. **跨券商验证 = 跨品种同款机制**:回测页勾选 → 同参数在其它有数据券商各跑一行,
   backtests 按 (strategy_id, symbol, broker) 存,验证行只进健壮性明细不参与排名;
6. **判读口径**:跨品种可以死(品种性格),**跨券商必须活**(同一商品三个镜头,
   分歧 = 查数据/时区/点差,不毙策略);
6b. **默认券商 = MetaQuotes-Demo(研发尺, 唯一20年全量)**;升级 live 到其它券商
   时须**迁户口**:strategies.broker 改为目标券商 + 在其数据上跑回测(成为新的
   户口行/对账基准),原 MetaQuotes 行降为跨券商验证行(20 年证据不丢, 换座位)。
   登记表单加券商选择(选项=下载 worker 的券商, 缺省=默认券商), 各券商精度各归各;
7. 停机可接受 → 单事务原位换主键,维护窗口首跑;一次性把读路径全链补完
   (单券商下 broker 恒等于默认值,161 测试全程护航,第二券商来时零代码只灌数据)。

## 附加功能:跨券商对账(2026-08-19 Frank 提出, 复用对账内核)

对账的本质 = 同一信号流在两面镜子下的逐笔对照 → 镜子可换:
**回测@券商A vs 回测@券商B**(复用 compute_reconcile 配对逻辑, 输入换成两份回测逐笔)。
比回测vs实盘更干净(两边确定性重放, 无执行噪声, 不需要被原谅口径), 差异100%归因数据。
读数: 笔数匹配率(差异伤不伤策略的终审)/配对时间系统偏移(时区错位现形)/总账偏。
与 bar 级数据验证分工: **bar级查"数据差多少", 笔级查"差异伤不伤策略"**。
窗口 = 两券商数据的**交集**[max(A起,B起), min(A终,B终)](对比三铁律·统一时间);
两边同用引擎 start_ts 空仓起跑对齐(防交集前持仓造成的占位级联假差异),
实际可比首笔 = 交集起点+暖机段。
判读预登记(草案, 届时校): 配对率 ≥85% 且总账偏 ≤10% = 同世界(增量数据即可);
时间系统偏移 = 时区错位, 全量独立成尺。

## 性能检查点(2026-08-18 Frank 点名, 按测量决定不按猜测预建)

- 库里**永远没有拼接串**(无 XAUUSD@OD): 两列干净分开, 查询加 AND broker=$n, 不做字符串拆解;
- ADD COLUMN + DEFAULT = 元数据秒级(PG11+), 唯一贵的是主键索引重建(窗口内一次);
- 主键列序两难: broker **末位**(本方案) = 现计划零变化+漏改只错不慢;
  broker 第二位 = 三券商时代扫描零放大但漏改的查询会**悄悄退化成扫全品种索引**;
- **检查点: OANDA 全量灌入之前**, 用真实 EXPLAIN 对比 load_m1/缺口检查/regime 构建
  三条热路径 → 需要时再开一个窗口调列序或补二级索引(届时数据翻倍, 实测说了算)。
