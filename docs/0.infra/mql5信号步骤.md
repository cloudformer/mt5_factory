# MQL5 信号频道步骤(2026-08-18 定)

> 口径(全系统统一): **一个卖家账号 → 多个信号;每个信号 = 一个 MT5 账户 + 一个 Windows worker(1:1:1)**。
> 只走 Signals 不上 Market(卖 EA/指标要交出代码, 与信号服务哲学冲突)。
> MQL5 角色 = **获客器 + 公证处**(平台代记战绩的公信力), 不是主营收入。
> 前提铁律: **橱窗只放判过的货** —— live 信号之前, 策略必须走完漏斗(双尺 + 成本压力 + demo 对账)。

## 第 1 步 · MQL5 注册 + 卖家认证(现在就可做, 与漏斗零冲突)

- [ ] mql5.com 注册账号(**用护照上的真名**, 后面实名要求一致)
- [ ] 手机号绑定验证
- [ ] Seller 注册: 上传护照照片页, 等人工审核(几个工作日)
- [ ] (可后补)配置收款方式(银行转账/其支持的支付渠道) → 提现到自己名下账户,
      记账走 Schedule C, 系统开销(云主机/VPS/电费摊算/设备)全部留凭证抵扣
- [ ] 练手(可选): 用现有 demo 账户挂一个**免费信号**, 把"建信号"流程走一遍

## 第 2 步 · 开专用信号账户(等 FABLE demo 对账达标后)

订阅者兼容性最大的配置(开户时照抄):

| 项 | 选择 | 为什么 |
|---|---|---|
| 类型 | **Live 真金** | demo 信号基本卖不动, 页面大字标注类型 |
| 券商 | **主流大厂**(IC Markets / Pepperstone / OANDA 级别) | 跨券商跟单品种命名对得上, Slippage 栏好看 |
| 持仓制 | **Hedging** | 市场主流, 订阅者兼容面最大 |
| 杠杆 | 1:100 | 足够; FABLE 单仓小手数, Max deposit load 会很好看 |
| 币种/本金 | USD, 数千起 | 美分账户像玩具 |

- [ ] 每个信号商品 = 独立开一个账户(铁律: 不同 worker 不共账户)

## 第 3 步 · 接进自己系统, 跑 FABLE 组合

- [ ] 新账户注册进 `mt5_hosts`(独立 worker, 角色 live), Windows 侧标准部署
- [ ] 挂**判过的** FABLE 组合(参数错开: 无门 1~2 个全天候 + 带门 2~3 个;
      同参数的门版+裸版不同挂 = 纯双倍敞口零分散)
- [ ] 手数按**组合历史最差月**倒推(资金曲线对比页把候选叠起来看合成回撤)
- [ ] mql5.com → Signals → Create Signal → 填 券商服务器 + 账号 + **只读投资者密码**
      —— 系统零改动, MQL5 远程观察账户, 战绩钟从此刻开始走
- [ ] 不同风格 = 不同信号(稳健型/激进型/黄金专版), 每个重复本步骤

## 第 4 步 · 橱窗即广告(淘宝逻辑)

- [ ] 信号描述区 + MQL5 个人主页放**自己平台的链接**(NoPain 同款玩法)
- [ ] 卖点写实话(我们独有的): 净 pips 为正 / bar 级决策跟单友好(滑点栏自证) /
      每单服务端 SL/TP(不死扛, equity 与 balance 曲线贴合) / 判读流程公开
- [ ] 定价: 前几个月免费或 $20 攒订户和评论 → 战绩过百周提 $30~50(平台抽 20%)
- [ ] 挂着零成本: 没人订也白得公证战绩页; 有人订 = 利息; 点进链接 = 获客
      → 阶段③自己平台收订阅, 不再交 20%

## 时间线挂钩(不抢跑)

```
本周: 成本压力 → 门对比 → demo 挂 FABLE     ← 漏斗主线(战绩的原料)
同时: 第 1 步注册认证(审核期正好重叠)
demo 对账达标(约 1~2 个月) → 第 2/3 步开户挂信号
战绩满月可收费; 满百周才是销售起量线 → 期间第 4 步持续引流
```
